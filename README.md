## Описание проекта
Программа реализует цветную визуализацию множества Мандельброта на комплексной плоскости с преобразованием функции в действительные числа. Приложение разработано с использованием стандартной графической библиотеки tkinter и поддерживает интерактивное масштабирование (зум) выбранных областей фрактала.

## Функциональные возможности
### Основной функционал
- 🎨 Цветная визуализация множества Мандельброта
- 🔍 Интерактивный зум выбранной левой кнопкой мыши области
- ⌨️ Кроссплатформенный сброс масштаба до начального состояния
- 🖥️ Математический расчет фрактала в действительных числах

## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** macOS / Windows / Linux
- **Библиотеки:** `tkinter` (встроенная)

## Установка и запуск
### 1. Клонирование репозитория
```bash
git clone https://github.com
cd mandelbrot_project
```

### 2. Активация виртуального окружения
```bash
source venv/bin/activate
```

### 3. Запуск программы
```bash
python3 main.py
```

## Управление
- **Левая кнопка мыши (зажать и потянуть)** — выделение прямоугольной области для приближения фрактала.
- **Правая кнопка мыши ИЛИ клавиша Escape** — мгновенный сброс масштабирования до начального состояния (работает на Windows, macOS и Linux).
